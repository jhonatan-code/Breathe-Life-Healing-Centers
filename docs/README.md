# docs/

Design and context documents for the new Breathe website.

**Start with [`00-INVENTORY.md`](00-INVENTORY.md)** — a review of everything supplied
and what's still missing before build.

## Folders

- `brand/` — brand manual, brand brief, logo files
- `content/` — page-copy briefs (Homepage, Alcohol, Family Program, Reviews)
- `context/` — the authoritative BLHC Content Client Profile; everything defers to it
- `design/` — visual references (currently: v1 landing-page screenshot)
- `seo/` — old-site sitemap, Semrush/GSC exports, backlinks, call export

Each folder has a `_text/` subfolder with plain-text conversions of the `.docx` files.

Nothing is built from these yet. Development starts once the design system is
resolved and the go-ahead is given.
